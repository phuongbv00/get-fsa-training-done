# Workflow — a new programme

From a module list to a verified programme with a syllabus per module.

| Step | Task | Notes |
|---|---|---|
| 1 | `references/program/tasks/agree_module_table.md` | everything else is derived from it |
| 2 | `references/program/tasks/derive_skeleton.md` | the four CSVs |
| 3 | `references/program/tasks/fill_schedules.md` | marks, day grid, topics, outcome mapping |
| 4 | `references/program/tasks/write_syllabus.md` | once per module, plan first |
| 5 | `references/program/tasks/verify.md` | the whole programme |
| 6 | `references/program/tasks/export_workbook.md` | only when the user wants the vendor forms |
