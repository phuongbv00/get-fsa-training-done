### 6. Course Objectives

Teams of 3 to 5 build one product in three sprints. Requirements, design and code are delivered a little more each sprint, never all up front.

| Name | Code | Description |
|---|---|---|
| Team delivery | PRJ-K1 | Plan, deliver and review a working increment as a team every sprint |
| Product engineering | PRJ-K2 | Build and defend a product from requirements to running code |

After completing the topic, trainees will be able to:

- Deliver a reviewed increment every sprint.
- Build and defend a working product as a team.
