# Workflow — a module's material

Everything a module's session plan asks of this feature, in the order that keeps
the pieces consistent — and, within each lesson, the order of how much a trainee
learns from them: slides, then the note, then the lab.

| Step | Task | Notes |
|---|---|---|
| 1 | `references/material/tasks/coverage.md` | the list of files the plan names, and what exists already |
| 2 | `references/material/tasks/propose_outline.md` | the handbook's outline; approved before it is written |
| 3 | `references/material/tasks/write_handbook.md` | `init` the theme; fixes the running domain and the versions first |
| 4 | `references/material/tasks/propose_outline.md` | per lesson, the deck, note and lab outlined together and each approved |
| 5 | `references/material/tasks/write_deck.md` | the approved deck, per lesson, in index order |
| 6 | `references/material/tasks/write_lecture.md` | the same lesson, following its deck's sections |
| 7 | `references/material/tasks/write_lab.md` | per lab, with a worksheet for group labs |
| 8 | `references/material/tasks/derive_appendix.md` | once the notes exist; outline it first if it is new |
| 9 | `references/material/tasks/coverage.md` | no `MAT-C01` left |
| 10 | `references/material/tasks/review_for_trainee.md` | before publishing |
| 11 | `references/material/tasks/verify.md` | the whole folder, with `--export` |
| 12 | `references/material/tasks/export.md` | the `.pptx` and `.pdf` handed out |

Steps 4–7 repeat per lesson. Never write a lesson's files before their outlines
are approved, and never take one lesson's approval as the next one's.

Assessments the plan names belong to the assessment feature; list them in the
report rather than writing them here.
