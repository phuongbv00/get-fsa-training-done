# Workflow — a module's material

Everything a module's session plan asks of this feature, in the order that keeps
the pieces consistent.

| Step | Task | Notes |
|---|---|---|
| 1 | `references/material/tasks/coverage.md` | the list of files the plan names, and what exists already |
| 2 | `references/material/tasks/write_handbook.md` | fixes the running domain and the versions first |
| 3 | `references/material/tasks/write_lecture.md` | one per note the plan names, in index order |
| 4 | `references/material/tasks/write_lab.md` | one per lab, with a worksheet for group labs |
| 5 | `references/material/tasks/derive_appendix.md` | once the notes exist |
| 6 | `references/material/tasks/coverage.md` | no `MAT-C01` left |
| 7 | `references/material/tasks/review_for_trainee.md` | before publishing |
| 8 | `references/material/tasks/verify.md` | the whole folder |

Assessments the plan names belong to the assessment feature; list them in the
report rather than writing them here.
