# Task — Write a group worksheet

The blank form each group fills in during a group lab, so session time goes
into the work and not into drawing tables.

## Inputs

| Input | Notes |
|---|---|
| the lab guide | what each group produces, step by step |

## Produces

`<subject>_lab_NN_worksheet.md` beside the lab.

## Steps

1. A title naming the lab, then a line for the group's name and members.
2. One heading per output the lab asks for, in the lab's order, with the table
   or list it needs drawn in advance: column headers, empty rows.
3. No instructions beyond "fill in each section"; the lab guide holds the steps.
   No sample answers.
4. Name the worksheet in the lab's `## Before you start`.

## Done when

Every output the lab's steps ask a group for has a place on the sheet, and the
folder still passes `FSA material verify`.

## Hands off to

Nothing.
