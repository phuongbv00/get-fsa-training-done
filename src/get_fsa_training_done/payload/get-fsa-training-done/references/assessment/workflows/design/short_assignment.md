# Workflow — short assignment (1-2 days)

Practical work a trainee finishes in one or two sittings, scoped tightly enough
that the brief stays short.

**Produces:** `<stem>.md`, `<stem>_rubric.md`, `<stem>.pdf`, and any supplied files.

| Step | Task | For a short assignment |
|---|---|---|
| 1 | `references/assessment/tasks/design/plan_scope.md` | task count from the level |
| 2 | `references/assessment/tasks/design/write_brief.md` | `Code: <LEVEL>_<SUBJ>_SA_<seq>`; a module with several short assignments keeps them parallel in shape |
| 3 | `references/assessment/tasks/design/write_rubric.md` | the level's rubric posture |
| 4 | `references/assessment/tasks/design/build_fixtures.md` | only if the brief supplies files |
| 5 | `references/assessment/tasks/design/render_pdf.md` | budget from the Duration line |
| 6 | `references/assessment/tasks/design/verify.md` | `--type short_assignment`; verifier `references/assessment/verifiers/short_assignment.md` |
