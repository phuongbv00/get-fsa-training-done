# Workflow — copying and AI-authorship checks

**Instructor-only. Run only when the user explicitly asks**, never as part of a
normal grading run.

| Step | Task | Question it answers |
|---|---|---|
| 1 | `references/assessment/tasks/grade/similarity.md` | did these two share a source? |
| 2 | `references/assessment/tasks/grade/ai_signals.md` | was this written by an AI? |

Run either alone when only one question was asked. An assignment that allows AI
use has no AI question to answer; skip step 2 for it.

## The rule that governs everything here

**No signal from this workflow changes anyone's grade, and none of it reaches a
learner.** Do not zero, reduce or cap a submission for a similarity score; do
not put a suspicion in a score sheet or a grade CSV; do not tell a trainee they
were flagged. The output is a ranked list for a human to review, ideally beside
an oral check. Nothing here is proof.

## Report

Keep the two conclusions separate: "this looks generated" and "these two share a
source" are different findings, and a submission can show one without the
other. Give a ranked list per question, the evidence quoted for each entry, a
confidence, and a verification step — usually an oral check on a named part of
their own submission. When the user asks for a table of the suspects' scores
with the evidence, make it instructor-only and say so. State that nothing has
been applied to any grade.
