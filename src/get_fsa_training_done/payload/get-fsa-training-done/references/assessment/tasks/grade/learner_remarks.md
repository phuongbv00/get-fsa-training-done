# Task — Write learner remarks

A short qualitative note per trainee for the class report: how they work, not
what they scored.

## Inputs

| Input | Notes |
|---|---|
| evidence | score sheets, submissions, the instructor's own notes |
| language | as the user asks |

## Produces

One remark per trainee, in a table or CSV the user names.

## Steps

1. Two or three sentences per trainee.
2. **No scores, no ranks, no numbers.** Describe strengths, gaps and working
   style: careful or hasty, structured or improvised, how they handle feedback.
3. Ground each remark in something seen in their work; say nothing about
   integrity checks.
4. Follow `references/common/style.md`, and `references/common/language_vn.md`
   in Vietnamese.

## Done when

Every trainee named has a remark of 2-3 sentences with no score in it.

## Hands off to

Nothing.
